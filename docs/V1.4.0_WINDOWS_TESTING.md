# OpenMimicry v1.4.0 — Windows interaction test

## Start

In PowerShell 5.1 from the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\win\start-openrouter-voice.ps1
```

Keep that terminal open, then start the desktop in a second terminal:

```powershell
.\scripts\win\desktop.bat
```

Open settings from the avatar gear or visit
`http://127.0.0.1:8000/dashboard`.

## Confirm the active LLM

The **Language model** card shows the exact provider and model. The default is
OpenRouter `openrouter/openai/gpt-4o-mini`; this is not GPT-OSS 20B. To use the
local 20B option:

```powershell
ollama pull gpt-oss:20b
ollama serve
```

Then select **ollama — ollama_chat/gpt-oss:20b** in the dashboard and click
**Switch backend**. A switch applies to the next turn. API keys stay in `.env`;
the dashboard never receives them.

## Voice checks

1. Wait for backend startup to finish. `small.en` is downloaded/warmed on its
   first v1.4.0 launch; later PTT presses reuse it.
2. Hold the microphone button, say a complete question, then release. Release
   finalizes the recording and the recognized transcript appears in history.
3. Enable Wake listen and say `Mimi, tell me a joke`. The default alias also
   accepts the common Whisper transcription `Me me, tell me a joke`.
4. Say a sentence without the wake name. It should appear faded as **heard,
   not submitted**, and no LLM call should start.
5. Repeat the exact wake command immediately. Both heard transcripts remain
   visible, but the repeated final is marked duplicate and is not submitted.
6. Ask at least three different questions rapidly. Assistant answers must stay
   in accepted order; an older response must never overtake a newer question.
7. Every reply should become visible when speaker playback starts, and every
   reply—not only the first—should produce audio.

If names are inaccurate, choose **Accurate — small.en**, add comma-separated
recognition aliases, and increase **End-of-speech pause** up to 3.0 seconds if
ordinary pauses still cut a phrase short.

## Character import

Create a ZIP containing exactly one `pack.yaml` and its sprite folders. In
**Avatar settings**, choose the ZIP, click **Validate & import**, select the new
pack, and click **Apply pack**. The full format and minimal example are in
[`character_packs.md`](character_packs.md#import-from-the-dashboard).

## Expected non-failures

- Dashboard history may show wake-listen speech that was not submitted; this
  is intentional observability, not conversation memory.
- Only the latest four completed exchanges are sent back to the LLM.
- Changing STT model can take time once because the new model is downloaded
  and warmed immediately.
