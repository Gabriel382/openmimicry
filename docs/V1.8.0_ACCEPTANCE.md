# OpenMimicry v1.8.0 acceptance checklist

## Automated

- `python scripts/check_versions.py`
- `python scripts/check_imports.py`
- `python -m pytest -q`
- `pnpm --filter @openmimicry/desktop-frontend test`
- `pnpm --filter @openmimicry/desktop-frontend typecheck`
- `pnpm audit --prod --audit-level=moderate`
- `python -m compileall -q apps packages`

## Windows/macOS/Linux desktop

1. Install the integrated profile and start backend, frontend, and desktop.
2. Confirm `/health/live` is 200 and `/health/ready` becomes 200 while idle.
3. Swap Sprite2D and Three.js packs; restart and confirm the last selection.
4. Load a licensed VRM/GLB and VRMA animation; exercise idle, thinking,
   speaking, emotion, gesture, and speed.
5. Activate two saved voices in succession. Confirm `refreshing`, controls
   blocked by readiness, no WebSocket loss, and two spoken replies.
6. Toggle memory local/on/off and confirm no process restart or raw-audio file.
7. In OpenRouter automatic web mode, send “hello” and confirm no web plugin;
   ask current weather and confirm research/citations when the model supports
   the provider plugin.
8. Register a temporary project and submit a Claude task. Confirm the installed
   Claude subscription is used and no Anthropic key is required.
9. Submit a PicoClaw task when installed; confirm absence is reported as
   unavailable rather than crashing chat.
10. Close during a disposable long task. Restart and confirm it is marked
    interrupted and a notification remains available.
11. Export/import a whole companion with and without reference audio. Confirm
    keys, memory, logs, and task history are absent.
12. Run `cargo fmt --check`, `cargo clippy -- -D warnings`, and `cargo test` in
    `apps/desktop/src-tauri`.

## Release stop conditions

- A second foreground turn is submitted before the previous LLM terminal event.
- Optional web/tools run while disabled.
- A voice/memory refresh leaves readiness permanently false.
- Local biometric or copyrighted companion files become Git-trackable.
- Task state disappears or remains falsely running after restart.
- Three.js resource disposal or transparent overlay behavior regresses.
