# OpenMimicry v1.3.0 — Windows voice and companion testing

## 1. Install or upgrade

Run from the repository root in Windows PowerShell 5.1 or newer:

```powershell
.\scripts\win\install.bat openrouter-voice
Copy-Item .env.example .env -ErrorAction SilentlyContinue
notepad .env
```

Set `OPENROUTER_API_KEY` in `.env`. The file is ignored by Git.

## 2. Start in this order

In the first PowerShell window, start voice and wait for `Application startup
complete`:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\win\start-openrouter-voice.ps1
```

This launcher intentionally runs Uvicorn without `--reload`. Windows system
TTS generates `comtypes` bindings inside `.venv` on first use; a source watcher
would otherwise restart FastAPI during the first spoken reply and disconnect
the desktop WebSockets.

In a second PowerShell window:

```powershell
.\scripts\win\desktop.bat
```

Starting the desktop before the backend can produce a temporary Vite WebSocket
proxy `ECONNABORTED`; it is avoided by the order above.

## 3. First-run voice setup

The first STT use downloads the selected faster-whisper model. Some
RealtimeSTT/PyTorch combinations also ask whether to trust the
`snakers4_silero-vad` repository. Confirm it once in the backend terminal; the
model is then cached. Windows may also request microphone permission.

The expected preflight line is:

```text
RealtimeSTT/RealtimeTTS imports OK
```

For Python 3.13 and newer, the installer includes `audioop-lts`, which supplies
the API removed from the standard library but still used by pydub/RealtimeTTS.

## 4. Controls and layout

OpenMimicry looks like one companion but uses three docked native windows:

| Surface | Purpose |
| --- | --- |
| Top toolbar | Drag, lock, hold-to-talk, wake listen, agent voice, settings, exit. |
| Avatar | Transparent PNG/animation and reply bubble; click-through. |
| Bottom composer | Text message and Send; independent of voice state. |

The top and bottom windows move with the unlocked avatar, remain always on top,
and reserve screen space when a saved position is restored. Configure sizes,
gaps, colors, scale, visibility, and bubble timing in `config/theme.yml`.

## 5. The two microphone modes

### Push-to-talk

Hold the toolbar microphone or `Ctrl+Space`, speak, and release. PTT does not
require the avatar name. v1.3 allows up to eight seconds for a final transcript
after release so first-run/CPU transcription is not discarded prematurely.

### Wake listen

Enable the listening-waves button. The microphone waits continuously, but a
turn is submitted only when the recognized utterance begins with a configured
name:

```text
Mimi, what time is it?
Hey Mimi, explain this error.
```

The name and punctuation are removed before the command reaches the LLM.
Ordinary background conversation is ignored. The default name is `Mimi`.

Click the gear, open the Voice card, edit **Wake name**, and choose **Save
name**. The dashboard stores it in ignored `config/user.yaml`; restart-safe
configuration precedence is:

```text
app.yaml < profile < user.yaml < OPENMIMICRY__... environment variables
```

The advanced `continuous_listening` configuration still accepts every final
utterance without a name, but it is not exposed by the normal toolbar.

## 6. Agent voice, text, and thinking

Agent voice controls TTS output only. Turning it off never disables text input
or reply bubbles. Both typed and spoken turns publish `LLMStarted`, giving the
Sprite2D character a visible `thinking` animation before reply text or speech.
The existing structured LLM reply still controls allow-listed emotion and
action cues.

## 7. Verification

Open the dashboard from the gear and confirm:

```text
Input: realtimestt (microphone) · Output: realtimetts (audio)
```

Then test, in order:

1. Send text with agent voice off; the bubble must complete.
2. Turn agent voice on and send text; the bubble and system TTS must both work.
3. Hold PTT, say a command without `Mimi`, then release.
4. Turn on Wake listen; ordinary speech must be ignored.
5. Say `Mimi, tell me a short joke`; one turn must be submitted.
6. Drag the top grip, lock the avatar, and confirm it no longer moves.
7. Open another application and confirm all three companion surfaces remain on
   top.

Developer checks:

```powershell
.\scripts\win\test.bat
pnpm.cmd --filter @openmimicry/desktop-frontend build
.\scripts\win\doctor.bat
cd apps\desktop\src-tauri
cargo fmt --check
cargo clippy -- -D warnings
cargo test
```
