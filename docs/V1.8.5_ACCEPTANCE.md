# OpenMimicry v1.8.5 acceptance

- [ ] A native Windows Claude install is found even when the backend inherited
  a stale `PATH`.
- [ ] A legacy `claude.cmd` installation is launched through `COMSPEC`.
- [ ] A missing CLI produces `cli_missing` with an actionable path message.
- [ ] A missing working directory produces `working_directory_missing`.
- [ ] Claude stderr survives a non-zero exit and appears in the terminal task
  update, result, journal, notification, and dashboard.
- [ ] A fast terminal update is replayed to a subscriber that attached after
  completion.
- [ ] Runtime readiness reports CLI version, auth state, working directory,
  permission mode, and persistent journal path without a model request.
- [ ] Existing v1.8.4 `config/user.yaml` files load without modification.
- [ ] No unrelated parent-process secret is copied into the Claude child
  environment.
