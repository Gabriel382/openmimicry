# OpenMimicry v1.9.0 user guide

This guide covers the v1.9 settings added to the browser dashboard at
`http://127.0.0.1:8000/dashboard`.

## 1. Companion identity and persistence

Configure **Personality** before exporting a companion:

- **Assistant name** is the character's own name.
- **Aliases** are the wake-name alternatives recognized by voice input.
- **Prompt** defines behavior and style but cannot be replaced by a memory
  fact about the user.

Use **Companion profiles → Export current companion** to produce a v2 profile.
It contains the avatar/runtime, 3D transform and aliases, selected voice,
personality, assistant name, and aliases. A voice reference is included only
when explicitly requested and consented to. Treat such exports as private
biometric material.

When a profile is activated, OpenMimicry prepares its voice and avatar first,
then persists the profile as the startup selection. If preparation fails, the
previous companion stays active. Selecting a pack or voice manually becomes
the new standalone startup choice.

## 2. Input and output language

The language controls are independent:

| Setting | Effect |
|---|---|
| Input `en` | English-only speech recognition model. |
| Input `fr`, `es`, or `pt` | Multilingual recognition constrained to that language. |
| Input `auto` | Faster-Whisper detects each utterance. |
| Output language | The LLM is instructed to answer in this language. |
| Output `auto` | The answer follows the current conversational language. |

Changing input language may warm a larger multilingual model. Controls are
temporarily disabled while the backend refreshes; a failed warm-up rolls back.
Text input remains available.

## 3. Internet research

For OpenRouter, choose one of:

- `off`: never request web research;
- `auto`: research explicit current/web questions, but not greetings or normal
  conversation;
- `always`: attach research to every request, mainly for diagnostics.

In `auto`, ask directly: “Search the web for today's weather in Paris” or
“What is the current release of …?”. Ask “include sources” when clickable
citations are wanted. Visible answers may retain links; speech removes URLs and
citation markers so the companion does not read them aloud.

Whether research is available still depends on the selected provider/model.
Ollama remains offline unless a separate research-capable adapter is supplied.

## 4. Claude Code projects

### Configure the local subscription

Install and sign in to Claude Code normally, then verify:

```powershell
claude --version
claude auth status
```

In **Tasks → Claude settings**, choose:

- CLI: normally `claude`;
- authentication: `subscription` to use the local Claude login, or `api` to
  use `ANTHROPIC_API_KEY`;
- permission mode: `acceptEdits` is the default non-interactive mode;
- model: optional Claude Code model name;
- working directory and maximum turns.

Run the readiness check before spending a model request. For each repository,
open `claude` interactively once in that directory and accept workspace trust.

### Register and use projects

Register an absolute project root and a memorable name. OpenMimicry stores a
cheap Git fingerprint and the last successful provider session. The session is
resumed only while the repository fingerprint is unchanged; a checkout/index
change invalidates stale context without rereading the whole project at every
request.

Examples:

- `Claude, add a unit test for the parser.`
- `Ask Claude to fix the README in OpenMimicry.`
- `Launch Claude to inspect the build failure in my-project.`

The avatar confirms submission immediately. Claude continues in parallel with
ordinary chat. The task journal survives restarts, and the desktop notification
button glows when a terminal result arrives. Open the dashboard to inspect
progress, stderr, result, and notifications.

## 5. Optional local tools

Tools are deterministic commands checked before ordinary LLM chat. They are
off by default.

| Capability | Example | Guardrail |
|---|---|---|
| Browser | `Open https://example.com` | HTTP(S) URLs only. |
| Music | `Play Blue Monday on Spotify` | Opens Spotify search. |
| Text file | `Create a text file named notes.txt containing ...` | New `.txt` only, first allowed root, never overwrites. |
| Folder | `Open the folder C:\\Work\\demo` | Must be inside an allowed root. |
| Application | `Launch editor` | `editor` must be an exact configured alias. |
| Alarm | `Set an alarm for 18:30` | Local 24-hour time; restored after restart. |

The reply to a file-write request confirms the filename and does not speak the
file contents. OpenMimicry never converts arbitrary model text into a shell
command.

For a custom service or Android bridge, choose the endpoint provider. It
receives:

```json
{"text": "the user's request"}
```

and returns:

```json
{"handled": true, "spoken_reply": "Done."}
```

Use `handled: false` to let the request continue to normal conversation.

## 6. Import an original creator VRM ZIP

Torikinoko and MINIUS are supported through local presets, not redistributed
assets.

1. Obtain the original creator archive and review its current terms.
2. Open **Avatar settings → Import original VRM creator ZIP**.
3. Choose `Torikinoko — SyakudoNyoron` or `MINIUS — brochiManac`.
4. Enter a lowercase private pack ID and choose the original ZIP.
5. Import, then select the resulting pack. Its `vrm` kind automatically selects
   the `threejs` runtime.

The hardened importer accepts one VRM, checks archive traversal/symlinks and
size limits, verifies the glTF container, discards auxiliary PSD/FBX/Blend
files, and writes credits to the private local manifest. The source archive
and model are ignored by Git.

Creator references:

- Torikinoko, SyakudoNyoron: <https://wakuaru.com/>
- MINIUS, brochiManac: <https://brochimanac.booth.pm/items/6014250>

## 7. 3D transform and animation aliases

Use Avatar settings to adjust scale, target, X/Y/Z position, X/Y/Z rotation,
camera framing, and global animation speed. Values are absolute and saved per
pack, preventing per-message drift.

Animation aliases map OpenMimicry lifecycle/gesture names to embedded clip
names in the imported model:

```json
{
  "idle": "Breathing",
  "listening": "ListenPose",
  "thinking": "ThinkLoop",
  "speaking": "Talk",
  "happy": "Joy",
  "error": "Confused",
  "wave": "WaveHand",
  "celebrate": "Victory"
}
```

Only these eight keys are accepted. If a custom clip is missing, the Three.js
runtime falls back to its standard candidates instead of failing the avatar.

## 8. Private data and source control

The default redistributable packs `mimic_blue`, `octomimic`, and
`octomimic_vrm` remain in Git. New character art, creator archives, personality
overlays, voice references/profiles, companion exports, memory, task history,
logs, credentials, and `config/user.yaml` stay private by default.

Before publishing a companion profile, verify every model, image, animation,
voice, and provider term yourself. OpenMimicry's MIT license covers its own
source, not imported content.
