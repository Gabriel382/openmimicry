# OpenMimicry v1.4.2 — Windows non-blocking voice test

This matrix targets two reported failures: PTT freezing after
`Immediate stop requested, aborting playback`, and live wake receiving finals
without consuming or sending them until the mode was disabled.

## Start cleanly

Close every older OpenMimicry backend and desktop process. From the repository
root, run:

```powershell
.\scripts\win\install.bat openrouter-voice
powershell -ExecutionPolicy Bypass -File .\scripts\win\start-openrouter-voice.ps1
```

In a second terminal:

```powershell
.\scripts\win\desktop.bat
```

## PTT recovery matrix

1. Hold PTT, say `Hello Bruno, how are you doing?`, and release.
2. Wait for the answer to begin speaking, then hold PTT again and ask a second
   question. PTT must enter listening within a fraction of a second.
3. Repeat for a third question. All three user turns must appear and all three
   LLM replies must appear. Later audio must not queue forever behind turn one.
4. Send a typed message immediately after interrupting an answer. It must
   appear in the conversation without waiting for audio cleanup.

A difficult Windows driver may produce these recovery lines; they are bounded
and the application must continue:

```text
TTS turn 1 stop call exceeded 0.35s; continuing recovery off-loop
TTS turn 1 worker did not stop within 2.0s
TTS turn 1 worker lane replaced after failed stop
TTS turn 2 queued
```

## Live-wake matrix

1. Enable live wake once. Do not toggle it off between questions.
2. Say `Mimi, what is your name?`, then remain silent for the configured
   end-of-speech pause.
3. The terminal must promptly show the following sequence:

   ```text
   STT final received: chars=...
   SpeechController: wake final dequeued: chars=...
   SpeechController: wake transcript accepted: 'what is your name?'
   Turn 0001 queued
   ```

4. Wait for the answer, then repeat with two different name-prefixed commands.
   Each accepted final must be sent without disabling live wake.
5. Say one phrase without `Mimi` or a configured alias. It should appear in
   history as rejected and must not be sent to the LLM.

## Diagnostics

If a step fails, download **Settings → Diagnostics → Download bundle** before
restarting. If the page is unavailable, run:

```powershell
.\scripts\win\collect-diagnostics.bat
```

Send the versioned ZIP and identify the failed matrix step. The collector
excludes `.env` and API-key values but can contain recognized transcripts and
local paths, so review it before sharing.
