# OpenMimicry v1.6.4 Chatterbox acceptance

## Upgrade safety

Back up `.env`, `config/user.yaml`, and the user data directory before
replacing source files. Do not copy an old `.venv` into a different machine.
The ordinary installer may reuse the existing `.venv` on the same machine.

## Install and start on Windows

```powershell
.\scripts\win\install.bat openrouter-chatterbox
powershell -ExecutionPolicy Bypass -File .\scripts\win\start-openrouter-voice.ps1
```

The same launcher remains canonical for Piper and Chatterbox.

## Runtime acceptance

The JSON report must include all of the following:

```json
{
  "passed": true,
  "after": {
    "chatterbox": "0.1.7",
    "perth": "1.0.1",
    "perth_watermarker_callable": true,
    "cuda_available": true
  }
}
```

The first repaired run may also include `perth_diagnostic` and
`after_perth_repair`. A later run must remain healthy without reinstalling
Perth or Torch.

## Direct diagnostics

```powershell
.\.venv\Scripts\python.exe scripts\install_chatterbox_runtime.py `
  --python .\.venv\Scripts\python.exe --check-only

.\.venv\Scripts\python.exe -c "import perth; print(callable(perth.PerthImplicitWatermarker))"

.\.venv\Scripts\python.exe -u -m `
  openmimicry.voice.workers.chatterbox_job --preflight --device auto
```

The middle command must print `True`; preflight must emit a JSON `ready`
record and exit zero.

## Interaction acceptance

With a consented reference WAV/MP3 selected, send three distinct text turns.
For every turn, verify that text appears, the reply is synthesized with the
reference voice, speaking animation terminates, and the following turn works.

## Failure evidence

If acceptance fails, attach the complete installer JSON plus the worker error.
The v1.6.4 worker reports the direct Perth import cause; a bare
`'NoneType' object is not callable` indicates old source files are still in use.
