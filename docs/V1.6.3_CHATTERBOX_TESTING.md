# OpenMimicry v1.6.3 Chatterbox acceptance

## Upgrade and install

From Windows PowerShell at the repository root:

```powershell
.\scripts\win\install.bat openrouter-chatterbox
```

Select Chatterbox and the consented reference in the dashboard, then use the
same launcher used for ordinary local voice:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\win\start-openrouter-voice.ps1
```

There is no `start-openrouter-chatterbox.ps1` in v1.6.3.

## Expected runtime report

On the reported RTX 4070 configuration, either the existing `cu126` runtime or
the currently working official channel must produce:

```json
{
  "passed": true,
  "selected_channel": "cu126",
  "selection_reason": "existing verified runtime"
}
```

If the previous v1.6.2 attempt already installed `cu118`, that complete runtime
may be preserved and report `cu118`; this is valid and avoids another 2.7 GB
download. Setting `OPENMIMICRY_TORCH_CHANNEL=cu126` explicitly requests a
one-time upgrade when desired.

## Interaction acceptance

Send at least three text turns. Each must:

1. appear immediately in history;
2. receive an OpenRouter answer;
3. synthesize the cloned voice;
4. leave the worker ready for the next turn;
5. end the speaking animation when playback finishes.

## Diagnostic probes

```powershell
.\.venv\Scripts\python.exe scripts\install_chatterbox_runtime.py `
  --python .\.venv\Scripts\python.exe --check-only

.\.venv\Scripts\python.exe -u -m `
  openmimicry.voice.workers.chatterbox_job --preflight --device auto
```

Force only the cached model preflight with:

```powershell
$env:OPENMIMICRY_CHATTERBOX_PREFLIGHT = "force"
powershell -ExecutionPolicy Bypass -File .\scripts\win\start-openrouter-voice.ps1
```
