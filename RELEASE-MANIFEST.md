# OpenMimicry v1.9.2 release manifest

## Contents

- Complete MIT-licensed OpenMimicry v1.9.2 source.
- Full companion profile v2 with atomic avatar/runtime, voice, personality,
  assistant identity, transform, rotation, speed, and animation-alias restore.
- User-scoped memory identity and speech-safe visible research citations.
- Deterministic automatic OpenRouter research routing.
- Independent English, French, Spanish, Portuguese, and automatic input/output
  language settings.
- Dashboard-configurable local Claude subscription/API settings, named project
  roots, guarded session reuse, concurrent tasks, durable progress, and desktop
  completion notifications.
- Optional provider-neutral local tool policy and replaceable endpoint contract.
- Generic private custom-VRM archive import with no creator-specific presets.
- Independent skeletal-clip and facial-expression discovery plus stable
  procedural lifecycle motion for clipless VRMs.
- Wake-off lifecycle gating and Chatterbox tool-result/tokenizer recovery.
- Saved Three.js rotation and lifecycle/gesture animation aliases.
- Existing bundled CC0 Octomimic VRM and the three Git-eligible default packs.
- Release notes, migration guide, user guide, verification record, issue text,
  creator-asset notice, machine-readable manifest, and checksums.

## Artifacts

- `OpenMimicry-v1.9.2.zip`
- `OpenMimicry-v1.9.2-SHA256.txt`

The source archive excludes environments, dependencies, build outputs, caches,
credentials, databases, logs, raw/reference audio, local characters,
personalities, task journals, memory stores, alarms, companion exports, and the
uploaded Torikinoko/MINIUS archives and models.

Claude CLI, PicoClaw, cloud services, provider credentials, imported models,
voice references, and user assets are not bundled and retain independent terms.
