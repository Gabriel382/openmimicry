# OpenMimicry v1.9.2 deliverables

## Release artifact

- `OpenMimicry-v1.9.2.zip` — complete clean source plus release, migration,
  verification, and manifest documentation.
- `OpenMimicry-v1.9.2-SHA256.txt` — checksum for the source archive.

## Included outcomes

- permanent wake-off and late-transcript admission guards;
- robust Chatterbox normalization, tokenizer retry, and worker replacement;
- generic private custom-VRM import with no creator-specific presets;
- universal front-facing 180° default for unsaved 3D models;
- separate skeletal-clip and facial-expression discovery;
- stable procedural lifecycle animation for clipless VRMs.

## Excluded private/runtime content

No credentials, `config/user.yaml`, local characters, uploaded creator archives,
voice references, private companions, personalities, memories, task databases,
logs, virtual environments, dependencies, caches, or build outputs are included.
