# OpenMimicry v1.9.1 deliverables

## Release artifacts

- `OpenMimicry-v1.9.1-stabilization-source-FRESH.zip` — clean source tree and
  release documentation.
- `OpenMimicry-v1.9.1-stabilization-docs-FRESH.zip` — v1.9.1 release notes,
  migration, verification, issue, notices, manifest, changelog, and this index.
- `OpenMimicry-v1.9.1-SHA256SUMS-FRESH.txt` — SHA-256 hashes for both archives.

## Included implementation outcomes

- single-source personality/wake identity;
- non-blocking language preparation and Brazilian Portuguese standard voice;
- deterministic companion voice activation and synchronized selectors;
- full-range VRM rotation, clip discovery, alias selectors, and protected
  export/remove controls;
- multilingual deterministic alarm recognition and operational logs;
- wake-compatible Claude substring routing and voice-ready acknowledgement;
- private-by-default local character and companion storage.

## Excluded private/runtime content

No API keys, user configuration, voice recordings, cloned profiles, imported
companion data, Torikinoko/MINIUS creator assets, memories, task databases, logs,
dependencies, or generated build output are included.
