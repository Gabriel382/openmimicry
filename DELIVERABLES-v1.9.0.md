# OpenMimicry v1.9.0 deliverables

## Release artifacts

- `OpenMimicry-v1.9.0-integrated-source.zip` — complete source with lockfiles,
  built-in redistributable characters, tests, scripts, and documentation.
- `OpenMimicry-v1.9.0-docs.zip` — collaborator review package.
- `OpenMimicry-v1.9.0-ISSUE.md` — standalone GitHub issue text.
- `OpenMimicry-v1.9.0-SHA256SUMS.txt` — artifact checksums.

## Included documentation

- release notes and migration guide;
- v1.9 user guide for companions, language, research, Claude, tools, private
  VRM import, transforms, and animation aliases;
- verification record and acceptance issue;
- third-party/creator-asset notice;
- machine-readable release manifest.

## Deliberately excluded

- Torikinoko and MINIUS archives/model bytes;
- local/imported characters and animations;
- voice references and private companion profiles;
- personality/user overlays, `.env`, tokens, keys, and credentials;
- memory/task databases, alarms, logs, caches, dependencies, environments,
  build outputs, and generated application bundles.

Use the dashboard's original-archive importer to install creator models locally
from a copy obtained under their current terms.
